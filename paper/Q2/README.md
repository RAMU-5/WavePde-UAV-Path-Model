## 参考解的构造(公平性协议,审稿人必查)

1. **图**:26 邻域体素图,只连自由格;边权 = 与波动介质**完全一致**的
   连续度量——水平速度 a_h(z) = 15·reg(z)(管制带),竖直椭球半轴
   a_z = 5 m/s + 恒定上漂 w = +1 m/s(即 w_grav 编码:上 6 / 下 4),
   每条边解一个二次方程取精确通行时间。
2. **站点格**:逐行复制 `solve_one_source.py` 的 nudge 逻辑,两方法
   在**完全相同的格点**之间路由。
3. **string-pulling(关键)**:26 邻域图在 (2,1,0) 类方向上必须走
   折线,原始 Dijkstra 时间系统性偏高(实测中位 **+2.2%**,最大
   **+5.2%**)——这不是波动法的误差,是图的角度离散误差。因此对每条
   图路径做"视线无阻挡 **且** 度量时间更短"的贪心捷径(度量感知:
   介质非均匀,纯视线捷径会把路径拖进低空慢速层,曾产生 6× 高估,
   已修复),得到更紧的合法上界 T_ref ≤ T_dij。
4. **波动侧标定**:减去 Q1/E1.1 在生产工作点实测的偏置 0.945 s。
5. **有效对**:两侧均有限 + 站间距 700–3000 m(全文统一口径)。
