gap = (T_wave − 0.945 s − T_ref)/T_ref;T_ref = 各向异性 Dijkstra +
度量感知 string-pulling(见下)。负中位数的含义:T_ref 是**可行路径
的时间 = 真最优的上界**(贪心捷径非全局最优),而有限波长的衍射又让
波动首达在多拐角场景里"抄圆角";真最优夹在两者之间。论文口径:
**"95% 的城市站点对上,波动到达时间与离散真值之差在 ±6.5% 以内;
系统性偏移 −4% 与参考解的上界余量同号同量级。"**

## 本实验抓到的生产 bug(论文 §5.2/§5.3 的方法学叙事)

真值对比暴露:生产 5 m 矩阵有 **71–86/118 站每源**的首峰漏检(最大
晚 +170 s / +230%)。机制 = Q1/E1.4 的教训在生产规模重演:源按 sum=1
(格数)归一 → 幅值 ∝ dx³;`min_peak_amp = 1e-6` 是在 50 m 网格上调
的,5 m 幅值小 1000×,远处/阴影区的弱首波低于阈值,探测器记到更晚的
强波包。修正 `1e-6·(dx/50)³ = 1e-9` 后(先在 3 个源上验证:重尾完全
消失,无新增负尾),全矩阵重算,gap 从 +4.7%/36% 收敛到 −4.1%/6.4%。
**已修进生产代码**(solve_all / solve_one_source / solve_backward 的
批量入口 + wave_api 文档),50 m 锚点行为逐位不变。

Fig. 4(b) 三个直方图就是这个故事:灰(旧阈值,重正尾被裁剪)→
红(50 m,λ/dx=0.12 欠分辨的宽分布)→ 蓝(5 m 修正,紧致)。
**gap 是分辨率与探测器的属性,不是方法的属性。**

## 参考解的构造(公平性协议,审稿人必查)

1. **图**:26 邻域体素图,只连自由格;边权 = 与波动介质**完全一致**
   的连续度量——水平 a_h(z) = 15·reg(z)(管制带),竖直椭球半轴
   a_z = 5 m/s + 恒定上漂 w = +1 m/s(w_grav 编码:上 6 / 下 4),
   每条边解二次方程取精确通行时间。
2. **站点格**:逐行复制 `solve_one_source.py` 的 nudge 逻辑,两方法
   在完全相同的格点间路由。
3. **string-pulling(必须)**:26 邻域图在 (2,1,0) 类方向必须折线,
   原始 Dijkstra 系统性偏高(5 m 实测中位 **+1.1%**,最大 **+5.0%**;
   50 m 中位 +2.2%)——是图的角度离散误差,不是波动法误差。贪心捷径
   要求"视线无阻挡 **且** 度量时间变短"(度量感知:介质非均匀,纯
   视线捷径会把路径拖进低空慢速层,曾致 6× 高估)→ 更紧的合法上界。
4. **波动侧标定**:减 Q1/E1.1 生产工作点实测偏置 0.945 s。
5. **有效对**:双方有限 + 站间距 700–3000 m(全文统一)。

## Table 3 素材（方法对照）

| | wave(本文) | Dijkstra+pull(参考) |
|---|---|---|
| 单源耗时(5 m,80.8 M 格,~2 G 边) | **49 s**(A100,4500 步) | **70 s** Dijkstra + 0.3 s pull(单核 CPU)+ 建图 ~9 min(摊销) |
| 输出 | 全域 T 场(任意终点 O(1) 读出) | 单源全域距离 + 前驱 |
| 全 118×118 | 118 解 ≈ 96 min;伴随/多色可降到 ~1 解/目的地 | 118 次搜索(可并行) |
| 风 / 各向异性 / 管制带 | 原生(PDE 系数) | 需解析度量逐边求解(本文推导了精确闭式) |
| 内存 | ~1 GB(float32 场) | ~60 GB(CSR 图) |
| 备注 | gap −4.1%/6.4% vs 参考 | 角度偏差 +1.1%(已用 pull 去除) |

诚实结论:在"算一个源到全域"这件事上两者同量级;波动法的优势在
(a) 全对/多目的地问题的渐近(伴随 1 解服务全部起点,Q4/E3 主题),
(b) 物理通用性(风、各向异性、管制带即系数,无需重推度量),
(c) GPU 吞吐与 T 场的连续可微输出(−∇T 直接出路径)。
