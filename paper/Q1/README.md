## 结论(论文可直接引用的数字)

**C1(首峰到达时间 ≈ 最优旅行时间)在四类解析基准上成立**:

1. **自由空间**(E1.1):生产工作点(dx=5 m, τ=0.4 s)RMS 点态误差
   **0.41%**,dx=2.5 m 时降至 0.13–0.27%。拟合速度 c_eff 误差:
   dx=20 m 时 1.9% → dx=2.5 m 时 **0.24–0.63%**。到达偏置与脉冲峰值
   时刻 t0 线性一致(Fig. 1b),减截距即标定——后续所有实验沿用。
2. **匀风对流**(E1.2,dx=5, τ=0.4):**Mach ≤ 0.3 时所有方向扇区
   中位误差 ≤ 1.2%,p95 ≤ 3.3%**(along/against/cross 分扇区统计)。
   M=0.5 时逆风扇区中位 27%:逆风波长 (c−q)τ = 3 m < dx,欠分辨——
   这是**测出来的适用边界**(补救:加大 τ 或细化网格),顺风扇区同点
   位仍只有 3.1%。
3. **升降不对称 / w_grav 编码**(E1.3):开放域竖直轴斜率拟合
   (45–100 m):上行 **5.91 m/s**(目标 6,误差 1.5%)、下行
   **4.00 m/s**(目标 4,误差 0.11%)@ dx=2.5;dx=5 时 2.6%/1.1%。
   编码按构造正确,误差为离散量级。
4. **单障碍绕射**(E1.4):与 taut-string 精确测地线
   (L*=185–194 m,翻越箱体)相比,标定后到达时间 gap 在
   **dx ∈ {10, 5, 2.5, 1.25} m 全部 ≤ 0.52%**;−∇T 追踪路径与测地线
   同伦类一致、几何贴合(Fig. 3a)。绕射/阴影区处理正确。

**收敛行为(诚实版,写论文时按此口径)**:点态 RMS 误差的拟合阶为
**0.6–0.9**,不是格式的标称 2 阶——观测量是宽带高斯脉冲的首峰时刻
(含峰检测与方向性数值色散),不是光滑解的 L2 范数;但工程上重要的
量收敛得快:速度(斜率)误差在 dx=5 已 ≈1%,偏置被标定吸收。论文中
**不要声称 2nd-order accurate**,改为:"pointwise arrival-time error
≤0.9% at the production operating point, decreasing monotonically
with dx; the fitted propagation speed is accurate to <1%."
(checklist 中"<1.5 → 查通量 Laplacian"的预判已按此修订:不是 bug,
是观测量的性质。)

**设计注记(写论文时要点)**:
- 竖井(Dirichlet 壁面波导)方案不可用——波导无 TEM 模,低通高斯
  脉冲被截止频率高通滤波后以模式群速度传播,实测慢 26–32%,这是物理
  而非数值缺陷。改为开放域沿竖直轴测量:各向异性+平流介质的竖直群速
  度在纯竖直波矢处取极值(上行 = cz0 + |w_grav| = 6,下行 = 4),轴上
  首达即竖直射线。
- 远场(>120 m)轴上 T(d) 变平、表观速度超过 cz:竖向波长 cz·τ 仅
  1.3–1.9 格,而横向算子(c_xy=15,λ=24 m)分辨良好,欠分辨竖直模被
  斜向数值模超车。主数字取分辨好的近场段,远场偏差作为已记录的数值

## 实验设计中的方法学要点(论文 §5.1 / 附录素材)

1. **峰检测偏置标定**:到达时间含恒定偏置 ≈ 脉冲峰值时刻 t0。所有
   误差指标都对 T vs r 做线性拟合:**斜率给出无偏的 1/c_eff**,截距即
   偏置,后续一律减去(Fig. 1b)。
2. **源尾巴防护**:高斯源(σ=1.5 格)的空间尾巴在 5–7 格内幅值约
   1e-5,会在脉冲峰值时刻被误判为"首峰"。`min_peak_amp`(锚定生产值
   1e-6 @ dx=5)+ 测量点距源 ≥ 8.5 格是硬性要求——这是 E1.1 设计中域
   取 600 m、测量壳层取 170–250 m 的原因。
3. **峰阈值随 dx³ 缩放**:源按 sum=1(格数)归一 → 连续源强与一切
   远场幅值 ∝ dx³。固定阈值会让细网格漏掉弱绕射首波:E1.4 修复前
   dx=2.5/1.25 出现 +10.6%/+28.6% 的假 gap(探测器跳到了更晚的强波
   包),改 `min_peak_amp = 1e-6·(dx/5)³` 后全部 ≤0.52%。**对生产代码
   的提醒**:若未来在非 5 m 网格上跑批量解,`solve_all.py` 的固定
   1e-6 需要同样缩放。
4. **海绵层厚度**:跨分辨率对比时海绵按物理厚度(40 m)固定,层数
   = 40/dx,否则粗网格的海绵会吞掉半个域。
5. **CFL 固定**:dt = 0.02·dx(CFL = 0.3,生产工作点),时间误差随
   空间误差同步缩放。
6. 管制带(reg_z_low/full)在解析实验中必须关闭。
