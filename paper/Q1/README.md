## 实验设计中的方法学要点(论文 §5.1 / 附录素材)

1. **峰检测偏置标定**:到达时间含恒定偏置 ≈ 脉冲峰值时刻 t0。所有
   误差指标都对 T vs r 做线性拟合:**斜率给出无偏的 1/c_eff**,截距即
   偏置,后续一律减去(Fig. 1b)。
2. **源尾巴防护**:高斯源(σ=1.5 格)的空间尾巴在 5–7 格内幅值约
   1e-5,会在脉冲峰值时刻被误判为"首峰"。`min_peak_amp = 1e-6`(生产
   值)+ 测量点距源 ≥ 8.5 格是硬性要求——这是 E1.1 设计中域取 600 m、
   测量壳层取 170–250 m 的原因。
3. **海绵层厚度**:跨分辨率对比时海绵按物理厚度(40 m)固定,层数
   = 40/dx,否则粗网格的海绵会吞掉半个域。
4. **CFL 固定**:dt = 0.02·dx(CFL = 0.3,生产工作点),时间误差随
   空间误差同步缩放。
5. 管制带(reg_z_low/full)在解析实验中必须关闭。
